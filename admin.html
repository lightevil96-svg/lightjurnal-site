Cara menerbitkan karya ke situs publik

  1. Siapkan file PDF final dan pastikan kamu berhak membagikannya. Jangan unggah file yang melanggar hak cipta atau memuat data pribadi.
  2. Buka repository lightjurnal-site ↗. Buat folder documents (jika belum ada) dan unggah PDF ke sana.
  3. Ekspor JSON dari formulir ini sebagai catatan metadata. Tambahkan karya ke daftar data pada script.js menggunakan format objek yang ada di DEMO_ARTICLES; gunakan path PDF relatif seperti documents/nama-berkas.pdf.
  4. Commit perubahan ke branch main. Setelah GitHub Pages membangun ulang situs, karya akan tampil untuk semua pengunjung.
